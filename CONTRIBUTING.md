# Contributing

JobShield AU is currently a portfolio prototype. Issues and pull requests are welcome for bug fixes, accessibility improvements, evaluation methodology, and clearly scoped product features.

## Local setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest -q
streamlit run app.py
```

Please do not submit real recruiter conversations containing personal or sensitive information to the repository.
